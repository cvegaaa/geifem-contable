# GEIFEM Contable — Workspace

El código de la aplicación vive en [`geifem-contable/`](./geifem-contable).

- Frontend: `geifem-contable/frontend/`
- Backend:  `geifem-contable/backend/`
- Base de datos: `geifem-contable/database/`
- Documentación: `geifem-contable/docs/`

El resto de archivos en la raíz (`package.json`, `_legacy-scaffold/`) son
únicamente para levantar la vista previa del frontend en este espacio de
trabajo. El despliegue real (Vercel + Railway + MongoDB Atlas) se hace
manualmente y de forma independiente.

Ver [`geifem-contable/README.md`](./geifem-contable/README.md) para
instrucciones de instalación y ejecución local.
